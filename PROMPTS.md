# Cine Stream Sprint 8


Build a responsive movie discovery web application named **Cine Stream** using React and Vite.

## Requirements

- Integrate the TMDB API for movie data.
- Display movies in a responsive grid.
- Create reusable movie card components.
- Add movie search functionality.
- Implement debounced search to reduce unnecessary API requests.
- Add favorites functionality using React Context API.
- Create Home and Favorites pages.
- Add loading states while fetching movie data.
- Use a clean and modern movie-streaming style UI.
- Keep the application responsive for desktop and mobile devices.
- Store the TMDB API key in an environment variable.
- Do not expose API keys in source code.
- Organize the project using reusable components and services.

## UI Prompt

Create a modern cinematic interface with:

- Responsive navigation bar
- Movie search bar
- Movie cards
- Movie posters
- Movie titles and ratings
- Favorites functionality
- Responsive movie grid
- Loading indicators
- Clean typography and spacing
- Mobile-friendly layout

## Development Prompt

Use React functional components and hooks. Keep API logic inside the services folder and use Context API for favorites state management. Write clean, reusable and maintainable code.

## Testing Prompt

Check:

- Movie API requests
- Search functionality
- Debounced search
- Movie rendering
- Favorites add/remove functionality
- Loading states
- Responsive layout
- Production build

## Deployment Prompt

Prepare the React/Vite application for production deployment. Ensure environment variables are configured correctly and sensitive `.env` files are excluded from GitHub.
