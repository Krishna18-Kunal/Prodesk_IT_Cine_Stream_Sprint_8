# Cine Stream

Cine Stream is a responsive movie discovery web application built with React and Vite. Users can browse movies, search for titles, view movie information, and save their favorite movies.

## Features

- Movie discovery using TMDB API
- Search movies with debounced search
- Movie cards and responsive movie grid
- Movie details and ratings
- Favorites functionality
- Responsive design
- Loading states
- Modern React component structure
- TMDB API integration

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- TMDB API
- Context API
- Git & GitHub
